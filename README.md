# Folder Reorganizer

Lightweight, zero-bloat Windows tool designed to clean up messy download directories, batch rename files with custom patterns, and automatically organize files by type.

---

### [Download Latest Windows Executable (v1.0.0)](https://github.com/arnxe/folder-reorganizer/releases/latest)
*(no installer, py setup, or admin rights required)*

---

## Key Features

* **Custom Batch Renaming:** Sequential numbers (`_1`), alphabetical suffixes (`_A`), Roman numerals (`_I`), random IDs, and flexible pattern rules (`{name}`, `{num}`, `{date}`, `{ext}`).
* **Smart Auto-Sorting:** Automatically group files into subfolders by category (*Images, Documents, Media, Archives, Code, Other*).
* **Extension Filtering:** Target specific file types (e.g., process only `.png` and `.jpg`) while leaving other files untouched.
* **Dry-Run Preview & Undo:** Interactive treeview preview lets you inspect changes before modifying disk files. Revert changes instantly with **Undo Last Run**.
* **100% Offline & Portable:** Runs as a standalone `.exe` with zero telemetry or background processes.
